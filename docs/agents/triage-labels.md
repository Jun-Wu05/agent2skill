# Triage 标签

各技能以五个规范的 triage 角色交流。本文件把这些角色映射到本仓库 issue tracker 里实际使用的标签字符串。

| mattpocock/skills 里的角色 | 我们 tracker 里的标签 | 含义                            |
| -------------------------- | --------------------- | ------------------------------- |
| `needs-triage`             | `needs-triage`        | 维护者需要评估这个 issue         |
| `needs-info`               | `needs-info`          | 等待报告人补充更多信息            |
| `ready-for-agent`          | `ready-for-agent`     | 规格完整，可交给 AFK agent 执行  |
| `ready-for-human`          | `ready-for-human`     | 需要人来实现                     |
| `wontfix`                  | `wontfix`             | 不会处理                        |

当技能提到某个角色（例如 "apply the AFK-ready triage label"），使用表中对应的标签字符串。

如需修改右侧一栏以匹配你实际使用的词汇，直接编辑即可。
